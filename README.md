# Framer template skills

Agent skills for my Framer templates. Each template has its own folder of skills that let Claude, ChatGPT and other AI agents add content and make changes without breaking the template's design system.

## Templates

| Template | What it is | Skills |
|---|---|---|
| Remy | A portfolio template for product and brand designers, with case studies, a blog and a contact form. [Live preview](https://remytemplate.framer.website) | [remy/](remy/) |

## What's in a template folder

- **README.md**: what the skills do and how to set them up in each agent.
- **skills/**: one folder per skill, each with a SKILL.md file. Agents such as Claude Code, Codex and Cursor read these directly.
- **claude-app/**: the same skills as one ZIP each, ready to upload to the Claude app.

## How to get them

1. Click **Code** at the top of this page, then **Download ZIP**.
2. Open the folder for your template and follow its README.

The skills are written for one template each and expect its pages, components and styles, so they only work with the template they belong to. The same skills also ship inside each Framer project, for Framer's own agent.
